## Как запустить

1. Установите Python с сайта [python.org](https://www.python.org/downloads/). При установке отметьте **Add Python to PATH**.
2. Скачайте проект и положите видео рядом с `app.py`, назвав его `video.mp4`.
3. Откройте терминал в папке проекта и выполните:

   ```powershell
   py -m pip install numpy opencv-python pygame
   py app.py
